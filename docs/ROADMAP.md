## 已知技术债

- **CI 只有发版门禁**：PR / push 无 lint/build 检查（单人开发可接受，协作前需补）
- 多套统计并存（百度 / GA / Clarity），可评估收敛
- README 徽章由发版钩子同步 Next 版本，但 HeroUI 徽章仍是手写「3+」

## 暂不做（明确排除）

- SSR 首屏直出数据：与 `useInView` 懒加载设计冲突，收益低改造成本高
- PWA 离线：热榜场景价值低
- 平台级历史趋势（如「较昨日」）：需要持久化存储，违背「无数据库、无后端」约束；客户端相对趋势（已实现的 ↑↓）已覆盖核心价值
